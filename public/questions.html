2023 • Mid-term Exam Easy

Explain the difference between supervised and unsupervised learning in machine learning.

This question tests your understanding of fundamental machine learning concepts...

Solution:

Supervised Learning: Uses labeled data where the algorithm learns to map inputs to known outputs. Examples: classification, regression.

Unsupervised Learning: Works with unlabeled data to find patterns or structure. Examples: clustering, dimensionality reduction.

Key differences include input data type (labeled vs. unlabeled), the presence of output variables, and types of problems solved.

2023 • Final Exam Medium

Implement a function to determine if a binary tree is balanced.

A tree is balanced when the height of the two subtrees of any node never differ by more than one...

Solution:

function isBalanced(root) {
  if (!root) return true;
  
  function getHeight(node) {
    if (!node) return 0;
    
    const leftHeight = getHeight(node.left);
    if (leftHeight === -1) return -1;
    
    const rightHeight = getHeight(node.right);
    if (rightHeight === -1) return -1;
    
    if (Math.abs(leftHeight - rightHeight) > 1) return -1;
    
    return Math.max(leftHeight, rightHeight) + 1;
  }
  
  return getHeight(root) !== -1;
}

This solution uses a bottom-up approach with O(n) time complexity.

2022 • Final Exam Hard

Implement a distributed system for processing large-scale data with fault tolerance.

Design a system that can process terabytes of data while handling node failures...

Solution:

A comprehensive solution would involve:

  1. Data Partitioning: Divide data into chunks using consistent hashing
  2. Replication: Store multiple copies across different nodes
  3. Failure Detection: Implement heartbeat mechanism with timeout
  4. Recovery Mechanism: Rebuild failed nodes from replicas
  5. Processing Model: MapReduce or similar paradigm

Technologies to consider: Apache Hadoop, Spark, or custom implementation with ZooKeeper for coordination.
