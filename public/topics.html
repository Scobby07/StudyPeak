Neural Networks

AI Recommended High Priority

Overview

Neural networks are computing systems inspired by biological neural networks. They form the backbone of many modern AI applications and are essential to understand for any AI/ML exam.

Key Concepts

  • Neurons and Layers: Understanding the basic building blocks and architecture
  • Activation Functions: Sigmoid, ReLU, tanh, and their characteristics
  • Backpropagation: How neural networks learn through gradient descent
  • CNN, RNN, GAN: Different types of neural network architectures

Exam Tips

Questions often focus on backpropagation calculations, choosing appropriate activation functions, and recognizing which type of neural network fits specific problems.

Database Normalization

High Priority

Overview

Database normalization is the process of structuring a database to reduce data redundancy and improve data integrity. This is a fundamental database concept tested in most exams.

Key Concepts

  • First Normal Form (1NF): Atomic values, no repeating groups
  • Second Normal Form (2NF): 1NF plus no partial dependencies
  • Third Normal Form (3NF): 2NF plus no transitive dependencies
  • BCNF: Boyce-Codd Normal Form and its applications

Exam Tips

Expect questions asking you to identify the normal form of a given schema, normalize a table, or explain the benefits of normalization in specific scenarios.

Time Complexity Analysis

AI Recommended High Priority

Overview

Time complexity analysis is fundamental to understanding algorithm efficiency. This topic appears in virtually every algorithms exam and technical interview.

Key Concepts

  • Big O Notation: Understanding O(1), O(log n), O(n), O(n log n), O(n²), etc.
  • Asymptotic Analysis: Best, worst, and average case scenarios
  • Common Algorithms: Sorting, searching, and their complexities
  • Space Complexity: Memory utilization analysis

Exam Tips

Focus on calculating the time complexity of given code snippets and comparing the efficiency of different algorithms for the same problem.

Design Patterns

Medium Priority

Overview

Design patterns are typical solutions to common problems in software design. They represent best practices evolved over time by experienced software developers.

Key Concepts

  • Creational Patterns: Singleton, Factory, Builder, Prototype
  • Structural Patterns: Adapter, Bridge, Composite, Decorator
  • Behavioral Patterns: Observer, Strategy, Command, Iterator
  • MVC Pattern: Model-View-Controller architecture

Exam Tips

Practice identifying which pattern is appropriate for specific scenarios and understanding the trade-offs between different patterns.
